# Jeremy Nduati - Portfolio Website

A modern, responsive portfolio website showcasing full-stack development projects including ShopStar and Fashion Fit.

## 🚀 Features

- Modern, responsive design
- Smooth animations with Framer Motion
- Showcases ShopStar E-Commerce Platform
- Showcases Fashion Fit AI Styling App
- Skills section highlighting technical expertise
- Contact section with links
- Deployed on Vercel

## 🛠️ Tech Stack

- **Framework:** Next.js 16
- **Language:** TypeScript
- **Styling:** Tailwind CSS
- **Animations:** Framer Motion
- **Icons:** Lucide React

## 📦 Installation

```bash
npm install
```

## 🏃 Development

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

## 🚀 Deployment

This portfolio is designed to be deployed on Vercel:

1. Push to GitHub
2. Import to Vercel
3. Deploy automatically

**Live on:** Vercel

## 📝 Sections

- **Hero:** Eye-catching introduction
- **About:** Personal background
- **Projects:** Featured work (ShopStar & Fashion Fit)
- **Skills:** Technical expertise
- **Contact:** Ways to reach out

## 🎨 Customization

Update project details in `app/page.tsx`:
- Add new projects
- Update skills
- Modify contact information
